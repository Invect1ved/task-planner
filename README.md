# Планировщик задач

Веб-приложение на ASP.NET Core и PostgreSQL. База `planner_db` создаётся при первом запуске.

## Возможности

- регистрация и вход;
- метод `POST /api/auth/makeAuthRequest` возвращает access token и refresh token;
- перед каждым действием клиент проверяет форму и срок access token, сервер проверяет подпись;
- задачи: название, необязательное описание, срок, дата создания;
- сортировка по дате создания и по сроку;
- выполнение, изменение, удаление;
- общий доступ по почте другого пользователя;
- уведомление в странице и в браузере, если срок ближе двух часов.

## Запуск

1. Служба PostgreSQL должна быть запущена на `localhost:5432`.
2. В `appsettings.json` после `Password=` впишите пароль пользователя `postgres`. Либо задайте переменную `PGPASSWORD`.
3. В папке проекта выполните `dotnet run`.
4. Откройте http://localhost:5088

## Бэкап

Структура базы: `database/planner_db.sql`.

Полный дамп уже заполненной базы:

```powershell
$env:PGPASSWORD = "пароль"
& "C:\Program Files\PostgreSQL\18\bin\pg_dump.exe" -U postgres -h localhost -p 5432 -d planner_db -f database\planner_db_data.sql
```

Этот файл и кладут в архив вместе с проектом.
